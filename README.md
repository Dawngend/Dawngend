### About

Computer Science student (Data Science specialization) at FEU Institute of Technology and a 100% SM Foundation Scholar, graduating July 2028.

Most of my work sits at the layer people skip: quantizing models so they fit real VRAM budgets, isolating vector namespaces so RAG stops leaking context between subjects, and writing async backends that survive concurrency. I care more about latency, data integrity, and hardware limits than about how the UI looks.

### Featured Work

**[ForgeAI](https://github.com/Emran-goat/forgeai)** · AMD Developer Cloud Hackathon · [live demo](https://forgeai-fbda.onrender.com/)
Automated 7-phase model compression platform for AMD Instinct MI300X GPUs via ROCm: knowledge distillation, pruning, and INT8/FP8 quantization. An Optuna-powered Pareto frontier engine searches the accuracy against latency tradeoff, with an async FastAPI + aiosqlite + WebSockets backend for live cloud benchmarking.
`Cut VRAM consumption by 60%+ and doubled QPS throughput.`

**[Andy's Hub](https://andyhub.org)** · personal production system
Stateful RAG academic reviewer with automated subject classification and subject-scoped vector isolation in ChromaDB, so retrieval never bleeds across subjects. Hybrid text and OCR ingestion with local caching, deployed on GCP VMs behind Cloudflare Tunnels.
`Cut ingestion and retrieval latency by 95%+, running 24/7.`

**[Sophy](https://github.com/Dawngend/Runtime-Terrors-TECHSPRINT)** · ACM Techsprint Hackathon
Study engine built for low-connectivity regions. Dual-API orchestration pairs Groq/Llama 3.3 for generation with NVIDIA NIM/Qwen 2.5 for JSON structural validation, which removes malformed-output failures rather than retrying past them. Hybrid pdfplumber/pytesseract OCR fallback with disk caching keeps it usable offline.
`100% structurally validated output, sub-second document reprocessing.`

**[BANGON](https://github.com/TadeyRuk/eGov)** · eGovPH Hackathon 2026 · [live app](https://bangon-egov.vercel.app/)
PII-secure identity integration for a national digital-government superapp. Replaced legacy cross-agency query loops with a tamper-evident blockchain verification layer, plus device binding and strict AAA security logging (a GDPR-comparable identity and PII protection model).

**[Dzuka Agri](https://github.com/asapthugn/dzuka-agri)** · lablab.ai Band of Agents Hackathon · [live app](https://frontend-coral-zeta-57.vercel.app/)
Multi-agent agricultural intelligence for smallholder farmers across Africa. I built the backend REST APIs and real-time geospatial ingestion pipelines.
`Nominated for the We The Peoples Africa Awards.`
